# Dot Notes

A simple, clean 2-page notes widget for Android. Dot-matrix design in black, red and white.

## Download
Open **[Releases](../../releases/latest)** on your Android phone and download **DotNotes.apk** (Android 8 or newer).
Allow "Install unknown apps" when asked. If Play Protect warns you, tap **More details > Install anyway**.

## Features
- **2 pages** – switch by tapping the page name on the widget. Rename them (e.g. TO DO, IDEAS).
- **Check off** – tap a note on the widget: it gets a red tick and a strike-through line.
- **Quick add** – red **+** on the widget opens a small pop-up. **+ Next** adds several notes in a row.
- **Widget themes** – AMOLED, Light and Clean, with adjustable background opacity (dot-gear on the widget).
- **Resizable** – drag the widget edges; the list scrolls.
- **App** – edit or delete notes, clear done notes, rename pages.

## Privacy
No account, no internet, no ads. Notes stay on your phone.
